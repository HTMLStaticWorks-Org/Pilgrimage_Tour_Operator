# SACRIDER Website Starter

A responsive multi-page front-end website concept for SACRIDER — “Every Faith. Every Sacred Journey.”

## Included pages
1. `index.html` — Home 1 (classic)
2. `home-premium.html` — Home 2 (premium)
3. `destinations.html` — searchable sample destination directory
4. `packages.html` — tour package enquiry categories
5. `itineraries.html` — 50 journey-plan concepts
6. `about.html` — brand purpose and principles
7. `contact.html` — enquiry form (client-side validation only)
8. `destination-detail.html` — reusable destination detail template

## Branding
- Horizontal logo: `assets/sacrider-horizontal-logo.png`
- Primary logo artwork: `assets/sacrider-primary-logo.png`
- Separate circular favicon artwork: `assets/sacrider-favicon-source.png`
- Trade Winds is used for brand styling; DM Sans and Playfair Display are used for readable content.
- Palette: Ivory `#FFFEF8`, soft gold `#E7C879`, antique gold `#B88B36`, deep gold `#80622C`.

## Run locally
Extract the ZIP, then open `index.html` in a modern browser. For best results, use a simple local web server (for example, `python -m http.server 8000`) and visit `http://localhost:8000`.

## Important scope and launch notes
- This is a static front-end starter, not a production booking platform.
- The destination page contains a limited illustrative sample, not 1,000 populated and researched records. The 1,000+ destination catalogue target requires verified research, data entry and editorial review.
- The itinerary page includes 50 plan concepts, not 50 fully researched, operational itineraries.
- Package cards are enquiry categories only. No prices, departure dates, availability, hotel/transport inclusions or operator credentials are claimed.
- The contact form validates in the browser but does not send, store or process personal data. Connect a secure backend or approved enquiry service before accepting real enquiries.
- No customer login or dashboard is included, consistent with the supplied project specification (“Dashboard: No”).
- Add verified business contact information, privacy policy, terms, cookie notice (if applicable), and current travel/access guidance before public launch.
- The favicon file is high-resolution source artwork. Generate production 16×16, 32×32, 48×48 and Apple touch icon variants during final asset preparation.
- Light/dark mode and LTR/RTL layout preferences are saved in browser local storage. RTL changes layout direction; it does not translate page content.
